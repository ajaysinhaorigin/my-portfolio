## What Is Prototype?

Prototype creates objects by **cloning** an existing object rather than using constructors.

<Callout type="definition">
  **Prototype** = Clone existing objects instead of creating from scratch.
</Callout>

---

## JavaScript Example

```js
const carPrototype = {
  wheels: 4,
  engine: 'V8',
  clone() {
    return Object.create(this);
  }
};

const car1 = carPrototype.clone();
const car2 = carPrototype.clone();
```

---

## When to Use

✅ Creating objects is expensive  
✅ Objects have many shared properties  

**Common:** JavaScript prototypal inheritance, object cloning.
