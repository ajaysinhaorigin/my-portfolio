## What Is Mediator?

Mediator centralizes communication between objects. Instead of objects talking directly, they communicate through a **mediator**.

<Callout type="definition">
  **Mediator** = Centralize complex communication through a mediator.
</Callout>

---

## TypeScript Example

```ts
class ChatRoom {
  showMessage(user: User, message: string) {
    console.log(\`[\${user.name}]: \${message}\`);
  }
}

class User {
  constructor(public name: string, private chatRoom: ChatRoom) {}
  
  send(message: string) {
    this.chatRoom.showMessage(this, message);
  }
}

// Usage
const chatRoom = new ChatRoom();
const user1 = new User('Alice', chatRoom);
const user2 = new User('Bob', chatRoom);

user1.send('Hi Bob!');
user2.send('Hi Alice!');
```

---

## When to Use

✅ Objects communicate in complex ways  
✅ You want to reduce coupling  

**Common:** Chat rooms, air traffic control, UI form validation.
