## What Is Template Method?

Template Method defines the **skeleton** of an algorithm. Subclasses override specific steps without changing the overall structure.

<Callout type="definition">
  **Template Method** = Define algorithm structure, let subclasses fill in steps.
</Callout>

---

## TypeScript Example

```ts
abstract class DataParser {
  // Template method
  parse() {
    this.openFile();
    this.extractData();
    this.parseData();
    this.closeFile();
  }
  
  openFile() {
    console.log('Opening file');
  }
  
  abstract extractData(): void; // Subclass implements
  abstract parseData(): void;   // Subclass implements
  
  closeFile() {
    console.log('Closing file');
  }
}

class CSVParser extends DataParser {
  extractData() {
    console.log('Extracting CSV data');
  }
  
  parseData() {
    console.log('Parsing CSV');
  }
}

// Usage
const parser = new CSVParser();
parser.parse(); // Calls template method
```

## When to Use

✅ You have an algorithm with invariant and variant parts  
✅ Subclasses should customize specific steps  

**Common:** Frameworks (React lifecycle), data processing pipelines.
