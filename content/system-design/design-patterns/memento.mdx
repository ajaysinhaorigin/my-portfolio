## What Is Memento?

Memento **saves** and **restores** an object's state without exposing its internal structure.

<Callout type="definition">
  **Memento** = Save and restore state.
</Callout>

---

## TypeScript Example

```ts
class EditorMemento {
  constructor(public content: string) {}
}

class Editor {
  private content = '';
  
  type(text: string) {
    this.content += text;
  }
  
  save(): EditorMemento {
    return new EditorMemento(this.content);
  }
  
  restore(memento: EditorMemento) {
    this.content = memento.content;
  }
  
  getContent() {
    return this.content;
  }
}

// Usage
const editor = new Editor();
editor.type('Hello ');
const saved = editor.save();
editor.type('World');
editor.restore(saved); // Restore to "Hello "
```

---

## When to Use

✅ You need to save/restore object state  
✅ Undo/redo functionality  

**Common:** Text editors, game save points, transaction rollback.
