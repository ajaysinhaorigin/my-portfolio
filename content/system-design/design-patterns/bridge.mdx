## What Is Bridge?

Bridge **separates** abstraction from implementation so they can change independently.

<Callout type="definition">
  **Bridge** = Separate what from how.
</Callout>

---

## TypeScript Example

```ts
interface Device {
  turnOn(): void;
  turnOff(): void;
}

class TV implements Device {
  turnOn() { console.log('TV on'); }
  turnOff() { console.log('TV off'); }
}

class RemoteControl {
  constructor(protected device: Device) {}
  
  powerOn() {
    this.device.turnOn();
  }
}

// Usage
const remote = new RemoteControl(new TV());
remote.powerOn();
```

---

## When to Use

✅ Avoid permanent binding between abstraction and implementation  
✅ Both should be extensible  

**Common:** Device drivers, GUI toolkits.
