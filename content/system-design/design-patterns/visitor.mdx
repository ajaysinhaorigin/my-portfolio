## What Is Visitor?

Visitor lets you add **new operations** to object structures without modifying them.

<Callout type="definition">
  **Visitor** = Add operations without modifying classes.
</Callout>

---

## TypeScript Example

```ts
interface Visitor {
  visitCircle(circle: Circle): void;
  visitSquare(square: Square): void;
}

class AreaCalculator implements Visitor {
  visitCircle(circle: Circle) {
    console.log(\`Circle area: \${Math.PI * circle.radius ** 2}\`);
  }
  
  visitSquare(square: Square) {
    console.log(\`Square area: \${square.side ** 2}\`);
  }
}

interface Shape {
  accept(visitor: Visitor): void;
}

class Circle implements Shape {
  constructor(public radius: number) {}
  
  accept(visitor: Visitor) {
    visitor.visitCircle(this);
  }
}

// Usage
const circle = new Circle(5);
const calculator = new AreaCalculator();
circle.accept(calculator);
```

---

## When to Use

✅ You need to perform operations on different object types  
✅ Operations change frequently but object structure is stable  

**Common:** Compilers (AST traversal), file system operations.
