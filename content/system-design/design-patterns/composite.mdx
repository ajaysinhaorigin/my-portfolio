## What Is Composite?

Composite represents **tree structures** where individual objects and groups are treated the same way.

<Callout type="definition">
  **Composite** = Treat single objects and groups uniformly.
</Callout>

---

## TypeScript Example

```ts
interface Graphic {
  draw(): void;
}

class Circle implements Graphic {
  draw() { console.log('Drawing circle'); }
}

class CompositeGraphic implements Graphic {
  private children: Graphic[] = [];
  
  add(graphic: Graphic) {
    this.children.push(graphic);
  }
  
  draw() {
    this.children.forEach(child => child.draw());
  }
}

// Usage
const group = new CompositeGraphic();
group.add(new Circle());
group.add(new Circle());
group.draw(); // Draws all children
```

---

## When to Use

✅ You have tree-like object structures  
✅ You want to treat individual and composite objects uniformly  

**Common:** File systems, UI component trees, org charts.
